# 画师交接包 · 黄金恶魔牙"亮态宝石"（待机态重绘）

> 建立日期：2026-09-14
> 需求来源：用户希望黄金恶魔牙复用普通恶魔牙 LV1 的"开火变暗+凹陷"效果。该效果在原版中由**两张本体美术切换**实现（#500 待机亮毂 ↔ #502 发射暗毂，时间轴本体互换），并非染色滤镜——**必须重画**。
> 交付后程序侧工作（已规划，画师无需关心）：新画导入为新 Character ID → 391 时间轴 f0 换用亮态 → 开火帧 REPLACE 回现有暗态（365）→ 循环自动还原。

## 一、需求一句话

给黄金恶魔牙（本体形状 365）重绘一版**"亮态"的待机宝石**：紫心提亮、内环由黑改为亮银白（凸起感），**枪体其余部分逐像素不变**。现有 365 将降级为"发射态（暗态）"，开火瞬间切换，形成 LV1 式的"亮→暗"开火反馈。

## 三、交付规格

1. **画布与配准**：与 `本体365-待机全图-1x.png` 完全同尺寸（94×22）、同位置；**只有宝石与内环区域（sprite x≈17~32、y≈33~47，即画布 x13~28、y6~20）重绘**，其余像素保持原样；
2. **风格目标**（参照 LV1 对比图）：
   - 紫色核心提亮为"发光的亮紫"（现暗紫 → 亮紫红高光）；
   - 宝石外围的**黑色内环改为亮银白高光环**（环上缘最亮、下缘带阴影 → 产生"凸起"错觉——与 LV1 #502 暗毂"上暗下亮=凹陷"正好相反）；
   - 金色枪体、品红装饰条纹、挂点位置全部不变。
3. **交付物**：透明 PNG（94×22，1x）；如方便可附 8x 预览图。

## 四、回收管线（交付后由程序侧执行）

交付 PNG → FFDec 导入为**新 Character ID**（不覆盖 365）→ 391 时间轴 f0 的 d2 本体替换为亮态 → 开火帧 REPLACE 回 365（暗态）→ 渲染验证 → 三处同步部署 → 实机确认。

## 五、背景技术结论（为什么需要重画）

LV1 的开火变暗 = #500/#502 两张独立美术的时间轴切换；"凸↔凹"的视觉错觉来自两张画的高光/阴影方向反转，**ColorTransform 只能整枪均匀压暗，无法实现局部变色与凹凸反转**，故必须重画（用户 20260914 拍板）。
