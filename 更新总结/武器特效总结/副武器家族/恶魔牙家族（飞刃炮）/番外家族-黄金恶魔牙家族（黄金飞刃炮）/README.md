## 20260912 对比联动结论（随本体家族三版本对比产出）

- **时间轴模板与 GH 常规恶魔牙完全一致**：f1 待机（本体＋basePoint/shootPoint=角色 104@d5/d7）→ f2 仅 StartSound → f3~f10 共享 8 帧 blend5 辉光 **369~390**（与常规 lv1~lv6 同一组角色，未复刻）→ f11 清理。
- **开火音与常规共用同一 StartSound 366**（GH 新音效）；受击/子弹配置与常规一致（`bullet/blue_motion` / `sub/goldflyBlade_bullet`）。
- **关键新证据（枪口烟雾之谜）**：GH 黄金时间轴里**同样不存在** 2.5 式枪口逐帧序列（2.5 常规 lv1 的 460/465~485 组）或任何专门枪口层——黄金与常规在 GH 侧唯一差异只是待机本体涂装。若玩家所见"黄金枪口烟雾"真实存在，其来源只能是**运行时开火代码在 shootPoint 处动态创建的对象**，而非时间轴资产。
- 2.5/3.4 无 goldflyBlade，老素材仅普通 flyBlade 家族可用（见本体档案映射表）。

## 前期实验教训（20260905，测试包内，正式仓库未动）

来源：`tmp-soya-family-test\黄金恶魔牙特效问题总结.md`、`gold-flyblade-25-restore\`

1. 曾三次（v1~v3）把 2.5 普通 `flyBlade_lv1/lv2` 时间轴（含枪口逐帧对象）复制进黄金本体，FFDec 回读全部成功，**游戏内枪口烟雾均未恢复**；测试包 sub1130 已回退（回退后 SHA-256 `A5028135DA5F...26A95`），回退前副本存 `gold-flyblade-25-restore\backup\`。
2. **结论**：黄金本体与普通恶魔牙不能按导出名直接一一替换；枪口表现可能不是本体时间轴直接播放，而是开火代码在 `shootPoint` 处运行时创建的对象。
3. **20260912 联动结论补强**：GH 黄金时间轴本就没有任何枪口专用层（见上节）——前期"把枪口对象搬进时间轴"的思路与 GH 现行结构互斥，**必须先确认目标效果到底由哪条路径提供**再动手。
4. **正式工作前置任务**（按前期总结建议）：追踪开火代码中黄金恶魔牙的发射特效创建入口 → 记录 shootPoint 生成对象的实际导出名与所属 SWF → 分版本渲染开火帧定位截图所示五阶段动画的真实 Symbol → 只替换该引用后实测。

## 已知注意事项

- 挂点通用教训适用（`basePoint`/`shootPoint` 为功能锚点非美术）。
- **素材汇总 `shapes\*.png` 不可作像素级参考（20260916 裁定）**：11.3副武器 全量导出的 shapes 目录均为矢量形状栅格化渲染（含平滑重采样）；且枪口顶弹组合体（365）的真实结构 = 363 枪 1:1 + **364 弹缩 50% 水平翻转只露弹头 ~15px**（SVG 矩阵实证 + 数值验证：50%复原色差12.3 vs 1:1复原色差51.5）。此前执行总结中"翻转 364 以 1:1 叠入 (19,−1)"的量测说法作废，以本条为准。画师参考一律用《素材-画师-挂点弹与枪体原件包-20260916》。
- 金色外观是当前版设计资产，若做"老特效回迁"，按黄金鞭炮先例通常**保留金色本体、只回迁特效层**——具体范围听用户安排。
- 受击/子弹如涉及公共名改绑，沿用死名改绑规则（全域扫描配置 bins＋脚本＋存档＋动态拼接后再动手）。
