## 通用（先读这里再动任何家族）

> ⚠️ **通用教训（电磁炮家族实证，2.5/3.4/新版所有武器适用）**：武器本体 sprite 时间轴里存在**挂点**——命名实例 `basePoint`/`shootPoint`/`armsPoint`/`rocketPoint`/`plasmaPoint`/`laserPoint`（名字包含即命中）。FFDec 静态导出里会看到实例内的**挂点标记**（方框加号或圆形加号，红/白/黑/透明任意配色，如电磁炮的红色象限方块），逐帧位置纹丝不动。它们是射点/基点等功能锚点（运行时读坐标出子弹用），**不是美术本体**：不是炮体配色、不是待机动画、更不是回迁对象。**三版实机全部隐藏**——`SWFLoaderManager` **按名字**扫描（与颜色形状无关）后 `visible=false`＋缩至 0.1（2026-09-09 用户纠正＋2.5 代码库与当前仓库双代码证实），挂点标记只出现在 FFDec 静态导出/对比图里，**不代表任何版本的实机观感，也不构成版本差异**。检查时务必与实际美术素材区分：逐帧静止的几何标记=挂点标记，随帧变化的才是美术。**术语规范**：**挂点**＝时间轴里的命名实例（mount point/锚点，即 basePoint/shootPoint/armsPoint/rocketPoint/plasmaPoint/laserPoint）；**挂点标记**＝挂点实例内的辅助作画（即 Flash 的注册点/锚点标记，方框加号或圆形加号，任意配色）。详见《武器视觉效果构成元素键》A1/C1 与 `副武器家族\电磁炮家族\` 审计。
