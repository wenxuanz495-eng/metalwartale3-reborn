## 一、现象与复现链

用户在 3.4参照修改版进月球关卡，加载屏报错中断：**"(11/11)正在加载敌人数据：加载swf错误[IOErrorEvent type="ioError"...]"**。用户同时提供两条历史线索：①早期 1.0 离线版也进不去月球关卡、后来修过；②怀疑与建立猛犸/苏拉档案无关（本次已证实无关，属参照版分发缺资源）。

**历史档案定位（用户提示在 F 盘冷备）**：`F:\超合金冷数据备份\端游端\1.0\` 各版本公告——1.2.4/1.2.5/1.26 三版公告同载"修复加载 100% 后无法进入……月球副本资源加载等问题"，1.2.5 公告第 8 条明确"**已修复月球关卡资源缺失、加载失败及无法进入的问题**"。⚠️ 对比 1.2.4 与 1.2.5 包体：swf 资源目录零差异，差异仅在 game.swf/server.exe 等——即**当年端游离线版的修法是代码侧**（1.x 基座 11.3 的月球关排场与 3.4 不同，不完全可比）；**本次 3.4 的病因与修法均不同**（见下），1.x 档案提供的是"月球关加载失败=资源缺失问题"的方向印证。

## 二、根因（数据级审计）

3.4 关卡表用**中文名引用**敌人（unit 行），运行时经敌表（enemy25）映射 id 后按 `swf\enemy\<id>.swf` 加载。用 3.4代码库 `reference-binary-data\5_enemy25_xml`（78 怪 name→id 表）＋`14_level280_xml`（280 关）对 `3.4参照修改版\swf\enemy\`（71 个 swf）做全量覆盖审计，**三处缺失**：

| 缺失 id | 中文名 | 被引用关卡 | 3.4 世代史 |
|---|---|---|---|
| `Interceptors_1` | 拦截机1号 | **1-4-0~1-4-4**（数据在册、素材 4.0 才补装，见 34 号档案 ccfb82d） | swf 未随 3.4 分发 |
| `Ground_laser` | 月面陆基激光炮 | **1-4-5/1-4-6/1-4-7**（排场 20 只） | **swf 从未制作，出场必加载失败**——41 号档案 c612670 定案；4.0 补做无声四符号素材（84,824B）后同时摘除关卡引用 |
| ~~`AlarmTower`~~ | ~~警报塔~~ | ~~1-1-21~~ | **⚠️ 2026-10-07 勘误（同日）**：初版审计未剥 XML 注释而误报——3.4 关卡表 1-1-21 的两行警报塔出兵行**原文即被注释**（`<!--<unit number="1">警报塔</unit>-->`，且 2.5 level16.xml 同位置同样注释、11.3 运行时表同），**警报塔在 3.4（乃至 2.5/11.3 全世代）从未实机出场，本就不引发加载失败**；回填该 swf 属防御性补齐（非必需、无害），保留 |

进月球关报"(11/11)"＝预载批次第 11 个文件 IO 失败（3.4 引擎按章节级敌人池预载）。月球关首踩 `Interceptors_1`（全表 14 行出兵行全部活跃），1-4-5~7 另踩 `Ground_laser`（6 行全活跃）。

**★审计方法论勘误（本次教训）**：关卡表 unit 行审计**必须先剥离 XML 注释**（`<!--…-->` 内的出兵行不出兵、不预载）——初版脚本不剥注释，把 1-1-21 的注释行误报为"现行主线（11.3）1-1-21 同雷"，经用户实机反证（11.3 该关可正常进入且无此怪）＋运行时构建 xmlClass11 与源码树逐字节比对后定位；严格注释区间判定重跑后，3.4 的真实活跃缺失＝Interceptors_1＋Ground_laser 两项，与实机症状完全吻合。

## 三、修复方案与决策点

- **采纳**：从 `4.0（原版参考）\4.0游戏\swf\enemy\` **字节级原样拷贝**三只 swf 入 `3.4参照修改版\swf\enemy\`（71→74）。4.0 版即档案记载的"3.4 数据在册、4.0 补装素材"，是 3.4 数据的世代正确配套；`AlarmTower.swf` 经哈希核对与 2.5 版**逐字节相同**（c34de794…，原版素材原样流传），来源无分歧。⚠️ 其中 AlarmTower 经同日勘误属**防御性补齐**（其 1-1-21 出场行在 2.5/3.4/11.3 三代均被注释，本不引发加载失败，见上表勘误行）——保留作资源完整性补齐，不影响正确性。
- 未采纳：改 3.4 关卡表摘除引用（伤数据原貌）；重制 swf（无必要）。
- **符号覆盖验证**（python 解析 SymbolClass，ffdec 交叉）：拦截机1号导出 `fly/shoot1/shoot2/die`＋`bullet1`，覆盖 3.4 敌表 imgList `fly,shoot1,shoot2,die`；月面陆基激光炮导出 `stand/move/shoot1/die` 覆盖 `stand,move,shoot1,die`；警报塔导出 `stand/shoot/die`＋`bullet` 覆盖 `stand,shoot,die`。三只全部满足。
