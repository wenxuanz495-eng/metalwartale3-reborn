## 档案结构规范（2026-09-29 用户裁定，前 16 档已按此重整）

每份档案 MD 固定四段：

1. **身份卡（速览）**——id/分类/涂装/三方状态/双名等一表速览。
2. **一、视听素材**——本体 swf（哈希/三方状态）、涂装与形态帧（imgList 各态说明、攻击态形象）、音频（swf 内嵌音效现状）、素材汇总夹、图鉴图标。
