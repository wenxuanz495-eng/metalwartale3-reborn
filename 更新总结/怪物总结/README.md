## 建档方式（2026-09-29 用户裁定：按图鉴顺序）

- 顺序以**游戏内图鉴**为准，编号＝图鉴序号；文件夹名 `图鉴号，图鉴名`（中文逗号）。
- **权威顺序清单**：`UI\book\BookUI.as` 构造函数硬编码的 82 条名称数组（enemyContent 按名跳帧）——已提取为 **`图鉴顺序-BookUI.json`**（本目录，全图鉴建档总清单）。图鉴顺序 ≠ 敌人表 index（如 01/02=index 0/1、03=index 4、04=index 6，中间夹着巡天者/蓝光飞碟/SAX-DJ）。
- 图鉴文案资料源：`D:\superalloy\世界观开发\规整档案\原版资料\原版机器人，角色介绍\`（超合金机器人介绍.docx 等；**谈到的怪物若图鉴无资料＝"资料不详"，如实标注**）。
- 每档一个子文件夹，**两份文件**：①`怪物名-档案-YYYYMMDD.md`（正档）＋②`README.md`（**路径索引**——该怪全部相关路径集中收拢：AI 类文件清单/敌人表与武器表锚点 index/当前仓与 2.5、3.4、11.3 素材四方 swf 路径/图鉴图标/文案源/比对数据/家族互链；路径缺失项如实注"无"或"待查"）。兄弟机型/同族怪在档内互链、只记差异。
- **图鉴图标 ≠ 实机形象属原版既有现象**（图标为 BookUI760 内嵌独立烘焙 JPG，涂装常与实机脱节，首例：悬浮炮塔 A 青色/B 紫色 vs 实机全绿）——各档如实记录，勿按图标色判断实机外观；**实机形象以 ffdec 导出帧目视核对为准**。
- **图鉴名 ≠ 敌人表名常见**（07"地面自动防御炮台"=表"地面自动炮台"=素材汇总"陆地防御者"三名并存；08"鸵鸟战机"=表"鸵鸟机器人"）——查怪时图鉴名/表名/素材夹名三套都要试，档案身份卡固定记双名。
