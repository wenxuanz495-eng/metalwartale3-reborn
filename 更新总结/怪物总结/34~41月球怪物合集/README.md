## 三、战役与关卡结构

- 内部关卡 ID `1-4-x`＝月球危机战役（V3.0），游戏内显示"第十章"起（显示编号烤在表内名，如 1-4-2="第十章 3.声东击西"；**勿把 1-4 读成第 1~4 章**）。
- **Boss 手法**：unit `type="boss"` 是月球危机唯一手法（主线 p1 时代用 `level@boss` 属性）——两套口径统计时分栏。
- **亮相型关卡 boss 定性**：红蛛杀手/拦截机2号/月面观察者/红色破袭者的 boss 标记＝各自初登场关配血条，此后全章降为 champion/普通怪复用；**设计 Boss**＝大天使（1-4-3）、钢铁暴牛兽（1-4-7，专属命名关）。
- **复用语境**：基线怪也大量复用于本战役——8.1 鸵鸟-S（月球危机 15 处主力）、6.1 风隼（1-4-21×3）、拦截机1号（24 关量产）等；卷内建档时与 8.1/6.1 档互链。
