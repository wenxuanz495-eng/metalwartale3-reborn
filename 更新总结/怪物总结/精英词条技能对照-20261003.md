# 精英词条技能对照（图鉴"精英怪技能介绍" ↔ EnemySkill 代码）

> 建档日期：2026-10-03（用户提出区分要求：**词条技能** vs **角色专属未启用技能**）。
> 数据源：图鉴"精英怪技能介绍"页签（用户截图）＋ `enemy\AI\EnemySkill.as`／`EnemySkillDefine.as`／`EventGroup.bodyAdd` 的 super 分支。

## 一、两套机制的定义（先分清）

| | **词条技能**（精英常用） | **角色专属技能** |
|---|---|---|
| 附加对象 | `type="super"` 词条怪（生成时随机） | 特定怪/特定关卡（硬编码） |
| 赋予方式 | `EventGroup.bodyAdd` super 分支：变色＋四维乘算（superAllRa）＋ **`skill.randomSkill(skillNum)`** | 各怪 Body/AI/关卡类里 `skill.setSkillArr([...])` 硬编码 |
| 技能池 | **`EnemySkill.normalSkillName` 13 项**（无放回随机抽，Plasma 可被排除） | 不限池（可为任意 label，含池外专属） |
| 可同时持有 | skillNum 个（随机组合） | 配置几个是几个 |
| 玩家可见文档 | 图鉴"精英怪技能介绍"页签 | 图鉴**不收录**（多数无介绍文） |

## 四、TACTICAL_MODE 关联

词条池＋21 个 label 全集（含池外）就是**原版已预研的敌人技能说明书**：反伤/强防/强伤/回血/强命/地雷/空投/追踪/曲射/等离子/EMP 全有轮子——重做攻防时优先复用这套框架而非另起炉灶。已知坑：Clear_Energy/EMP_5 两个 EMP 系 label 为空实现（真效果在池外 Slow_Missile 武器路径）；图鉴两处文案复制错误。
