# 副本关代码全解（精英 / 玩家VIP / 每周 / 特殊 / 公会战）

> **目标**：按用户要求摸清五类副本关在代码里的真身，并解决总览遗留的"特殊脚本类无实例化路径"矛盾。
> **实际修改**：无代码改动；产出本文＋`关卡总表-v2-246关.csv`＋`parse_levels.py` v2。
> **重大勘误**：总览初版"副本关全空名／特殊脚本类死代码"两结论**作废**。根因：`<name>/<specialClass>/<father>` 是 `<level>` 的**子元素**而非属性（E4X 里 `xml0.specialClass` 取子元素、`@specialClass` 才是属性），初版解析器只读了属性。重提取后证实：**全 246 关都有子元素名，99 关挂脚本类，26 个脚本类全部在用**。

## 一、接线机制（一句话版）

`LevelGroup` 构造循环按 id 首段给**家族兜底类** → 关卡 `<specialClass>` 子元素**覆盖**（`String(l_xml0.specialClass)` → `getDefinitionByName`）→ `LevelsDefine` 用 `xml0.child("name")` 取显示名。属性 `name` 与子元素 `<name>` 在战役关双写并存，**子元素才是运行时正身**。

## 二、五类副本的代码形态

| 副本 | id | 脚本类 | 机制要点 |
|---|---|---|---|
| **精英副本** | 2-1-0~44（45 关） | `SpecialExtraLevel_11` | ⚠️ **空壳类**（仅 `super.bodyDie`）——精英关实际是**纯数据波次关**，难度全靠表内出兵与数值倍率；45 关全带 Boss 名（精英突击者/精英先知/精英暴君/精英钢铁暴牛兽…） |
| **玩家副本（VIP 专属地图）** | **1-1-999** | `VipExtraLevel` | ①波次机：每 3 秒在玩家两侧视口外随机刷 `enemy0~9` 指令波，首发刷 `boss0~5`，清场＋15 秒后下一波并重启英雄 AI ②**VIP 时间即门票**：`vipData.mapTime` 每帧倒扣（1/6s 粒度），归零 `exitEvent()`＋弹 vip 界面——3.0.1"剩余时间退出不冷却"修复的就是这个 mapTime ③Boss 死 20% 掉紫芯片（按 Boss 等级 19/39/59 分档 ben-zhui/jing-zu/zhen-lie） |
| **每周副本** | 3-1-0~11（12 关） | `WeekExtraLevel`（无覆盖） | **名人堂玩家名 Boss**：Vincent/白金战车/炮王/叫兽/愤怒大机/Snow 幽明…——ROADMAP P2"名人堂装备"的来源关 |
| **特殊副本** | 4-1-0~10（11 关） | `SpecialExtraLevel_1..10` | 一关一个玩法类：死亡模式(_1)/无尽的深渊(_2)/时间竞速(_3)/极限生存(_4)/魂斗罗模式(_5)/**金币空间(_6)**/防爆试验(_7)/经验副本(_8)/金币副本(_9)/材料副本(_10)；**僵尸狂潮(4-1-10) 复用 _8** |
| **公会战** | 6-1-1~5 | `SpecialExtraLevel_11` | 五大区域地图（非洲/南美/北美/欧洲/亚洲），复用精英关机制 |

**金币空间样例（SpecialExtraLevel_6）**：继承 `Level_2_5` 倒计时基类；`failText="通关"`（时间到＝赢，与常关相反）；`allowRebirthCrystalNum=-1` 禁复活晶体；`BG.addAirLaserFort()` 造一台藏到 (-10000,-10000) 的隐形激光炮塔当**场外发球器**（这正是 3.0.4"金币空间清完怪无法结算"修复涉及的关）。

## 四、遗留疑点（新优化候选）

1. **精英副本紫芯片疑似失效**：紫芯片掉落代码写在 `ExtraLevel.bodyDie`，但 2-1 全部被 specialClass 覆盖为空壳 `_11`——若芯片没有其他掉落通道，**玩家现在打精英副本可能不掉紫芯片**。建议实机核查（4-1 材料副本/金币副本不受影响）。
2. `ExtraLevel` 孤儿基类处置评估（连同其回血球机制：精英关现在是否还有回血球？）。
3. `SpecialExtraLevel_11` 与 `ExtraLevel` 的关系（_11 是 ExtraLevel 的退化版还是另起炉灶）待考古，不影响使用。
