# 隐藏称号功能（称号界面按钮改版）

> 完成日期：2026-09-07
> 工作区：`D:\superalloy\metalwartale3-reborn.git`

## 一、目标

1. 称号界面（荣誉/成就面板的"已获得称号"页）右下角的单个大"使 用"按钮，改为 2×2 四个小按钮：
   - 上排：**使用称号**、**放弃称号**
   - 下排：**隐藏称号**、**显示称号**
2. 新增"隐藏称号"功能：称号保持使用状态（称号属性仍生效），但隐藏头顶的称号/红星对外显示（含 VIP 称号黄字）。"显示称号"恢复显示。
3. 隐藏状态随存档持久化，旧存档自动兼容（默认显示）。

## 二、实际修改

| 文件 | 修改 |
|---|---|
| `gameAll\honor\HonorData.as` | 新增 `hideHonor:Boolean` 公开字段（AMF 序列化自动随 `copyObj()` 入存档）；`inData_byObj` 用 `hasOwnProperty` 兼容旧存档（无字段默认 false）；`init()` 重置为 false |
| `gameAll\EventGroup.as` | `fleshHonor()` 首分支：`hideHonor == true` 时直接 `hero.headTitle.visible = false`（头顶小红星/VIP黄字/称号文本整体隐藏） |
| `UI\honor\HonorUI.as` | 新增 2×2 小按钮（**第二版，实机返工后重写**）：首版运行时克隆 use_btn 的方案实机失败（美术未渲染、无法交互），改为按 11.3ui 界面素材（501/504/636/638.png，114×36）纯代码绘制——双层圆角框（外圈暗描边 + 内圈发光亮边 + 近黑填充 + 顶部亮线 + GlowFilter 辉光），精确取色：黄色系（使用/放弃）RGB(253,170,0)/RGB(142,77,1)/填充(25,11,3)，悬停 RGB(252,212,3)；青色系（隐藏/显示）RGB(0,217,253)/RGB(0,108,180)/填充(6,16,24)，悬停 RGB(0,219,255)。SimpleButton 三态（up=常态、over/down=增亮），标签设备字体 14px 白色粗体居中 + 黑色投影。布局 2×2：网格中心对齐原按钮中心，下排底边对齐原按钮底边，间距 10。原 `use_btn` 隐藏 |
| `config\build\swf-script-patches.txt` | 登记 `UI\honor\HonorUI.as`、`gameAll\honor\HonorData.as`（构建清单 118→120） |

按钮状态逻辑：
- **使用称号**：选中已获得且非当前称号时可用（沿用原 useClick 逻辑）
- **放弃称号**：当前使用中称号非"无"时可用，置 `nowHonor = "no"`
- **隐藏称号**：`hideHonor == false` 时可用，置 true
- **显示称号**：`hideHonor == true` 时可用，置 false
- 不可用态与原按钮一致：整体 alpha 0.3 + mouseEnabled=false；"未获得称号"页四按钮整体隐藏
- "当前称号"文本在隐藏状态下显示"××（已隐藏）"

交互保障：SimpleButton 自带 hitTestState（完整 114×36 区域），悬停有增亮态，可正常点击。
