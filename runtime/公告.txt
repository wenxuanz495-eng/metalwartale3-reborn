【超合金离线优化海豹版 1.2.5 更新公告】

一、启动与存档
1. 请使用“启动游戏.bat”进入游戏，不要直接打开 game.swf。
2. 游戏关闭后，CMD 窗口及本目录的 Flash、server 后台进程会自动清理。
3. 存档位于 saves\game_save.bin。升级或替换文件前，请先备份整个 saves 文件夹。
4. 修改器会在写入前自动备份存档；游戏运行时不要同时使用修改器。

二、本次主要更新
1. 修复虚空存档、存档保存、修改器空白页及启动残留问题。
2. 修复加载 100% 后无法进入、玩家副本倒计时不刷新、月球副本资源加载等问题。
3. 修复挑战任务结算，并完善挑战任务冷却；收集和扫荡任务可重复接取。
4. 材料背包增加三页；晶体合成及材料商店空白问题已加固。
5. 掉落改为主动吸附，避免物品高速浮空；医疗箱默认禁止自动捡取，可在修改器中取消勾选。
6. 修复战车随机属性为 0 和长小数问题；修改器可重复修复旧战车。
7. 商店不再以问号显示定制商品价格。定制武器为 4000~9000 MB，高等级定制车身为 1000~2000 MB。
8. 兑换商城首次进入立即有货，5 分钟刷新一次，手动刷新花费 2 MB。
9. 儿童节爱心掉落提高三倍，可按数量 1:1 兑换雪花；相关活动取消兑换次数限制。
10. “累计充值值礼包”改名为“累计MB礼包”，“首充礼包”改名为“新手礼包”，充值按钮移除。
11. 兑换码界面已禁止交互，避免离线版本误操作。
12. 修改名称和切换已解锁头像不再消耗 MB；未解锁头像仍按原规则使用 G 币解锁。
13. server 可在黑窗口及 saves\client_errors.log 中记录客户端报错，方便定位问题。

三、注意事项
1. “禁止自动捡取医疗箱”默认勾选；取消勾选后，医疗箱才会参与自动吸附。
2. 修改器中的“一键完成当前任务”仍标注为“暂时无效”。
3. 若安全软件拦截启动脚本或 server.exe，请从隔离区恢复并将游戏目录加入信任区。

四、海豹 1.2 系列群友反馈问题处理汇总
以下汇总目前 1.2.5 的处理结果；少数受旧存档或电脑环境影响的问题仍建议继续复测。
1. 已修复激光相关卡死，包括机甲变身后使用激光可能卡死的问题。
2. 已加固存档系统：主存档写入前保留上一份有效副本，写入中断或主存档损坏时可自动恢复，并拒绝角色槽位异常归零的覆盖。
3. 已修复修改器概率性生成约 1KB 空存档、打开后不显示存档、旧修改器引擎被优先启动等问题；修改器保存前仍会自动备份。
4. 已修复战车无属性、随机属性全为 0 和长小数问题；修改器保留战车属性修复入口。
5. 已修复兑换商店首次无货、倒计时与刷新问题；兑换码 UI 已处理，离线兑换渠道保持关闭。
6. 已处理低等级重复弹出武器库芯片安装引导的问题。
7. 已修复挑战任务不结算及相关冷却问题，收集、挑战和扫荡任务的刷新逻辑已加固。
8. 已修复月球关卡资源缺失、加载失败及无法进入的问题。
9. 已修复玩家副本无法挑战，以及旧存档显示“冷却 0 秒”但永久无法进入的问题。
10. 已修复活跃奖励刷新不完整：活跃度达到 100 后，五档奖励全部领取才会同时重置活跃值、奖励状态和全部活跃任务。
11. 已处理 VIP 地图、决斗竞技场及特殊副本不刷新问题；旧存档仍请重点复测通关星级、下一关开放和周期刷新。
12. 首充入口已调整为新手礼包并按离线规则直接提供，不再依赖在线充值流程。
13. 已处理关卡掉落 G 币显示小数的问题。
14. 礼包兑换渠道已关闭；新闻公告中隐藏的版本补偿礼包作为原版彩蛋保留。
15. 游戏关闭后会自动清理 Flash、server 和 CMD 残留进程；服务器内存占用已进行限制和清理优化，仍会继续观察不同电脑环境下的表现。
16. “全军覆没”、VIP 关卡返回已完成地图后不立即给星、4-9/2-7 类似表现及“决战月都”相关反馈，当前版本已合并多项关卡与刷新修复，仍列为重点复测项目；若偶发不计星，可重新挑战并保留 client_errors.log。
17. 武器升级时点击后方槽位会连同前置槽位一起解锁，属于原版连续解锁规则，本版暂不作为故障修改。
