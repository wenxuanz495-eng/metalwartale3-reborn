# 项目现状

## 当前目标

把原本依赖 4399 页面、登录、支付和远程存档的游戏改造成可长期保存、可维护、可扩展的单机版本，同时尽量保留原游戏流程和资源。

## 已实现

### 离线运行

- 使用正式规则等级，不启用测试模式及测试水印。
- Go 后端提供静态资源、API 桩和权威存档服务。
- 游戏通过本地 HTTP 地址加载主体和分包资源。
- 启动器会检查后端状态，再启动独立 Flash Player。

### 存档

- `saves/game_save.bin` 是权威存档。
- 同步生成便于查看和修改的 JSON。
- SQLite 保存最近的历史版本。
- Flash SharedObject（SOL）不参与读取和回退。
- 提供便携版修改器和清除存档脚本。
- portable 游戏/修改器启动脚本与 1.2.3 对齐：根目录识别、API 预检、端口切换及退出清理均已启用；关闭可见窗口后会强制结束同目录后台进程，不再无限等待残留 Flash/浏览器 helper。
- 道具背包最低容量提升为 144 格；新角色直接生效，旧存档读档时自动扩容且不缩减更大容量。
- 材料背包在原始 36 格基础上增加三页（每页 30 格），最低容量为 126 格；新旧存档均生效且不缩减更大容量。
- 读档/存档会剥离虚空档：等级<=1 且无主武器/副武器/车辆的角色槽会被清空；服务端保存前也会剥离并写回清理后的数据，不再因默认名 4399小战士 漏网。
- M币出现 NaN 时自动归零。

### 商城与货币

- M币交易按照账户余额正常校验和扣款。
- 商城购买数量上限扩大到 9,999,999。
- 绿色芯片不直接出现在普通商店。
- 原材料和晶体类 M币商品合并为“自选强化礼包”。
- 定制装备、往期装备和现版本无法获取的精选装备加入商城，并按档位提高价格。
- 累计充值奖励改为读取账户当前持有的 M币。
- 成长礼包改为离线直接购买/激活。
- 等级和 G币的一步到位 M币入口被隐藏，M币主要用于材料、装备和可玩系统。

### 角色与成长

- 改名免费。
- 头像使用 G币永久解锁，并保存解锁列表。
- 全能训练支持输入提升级数。
- 战斗力、耐久和相关汇总使用大数值，避免 32 位整数溢出为负数。
- 主界面战斗力显示避免无意义的小数尾数。

### 战斗核心

- 普通、优质和稀有战斗核心均有批量开启入口。
- 玩家可以输入开启数量。
- 每次开启独立消耗一个核心和对应拆解器。
- 三档核心分别固定获得 5 万、10 万、20 万 G币及对应保底材料；稀有核心的三种高级合成材料为固定获得，不再按 10% 概率结算。
- 单次和批量拆解完成后显示实际奖励名称与合计数量，不再只显示拆解核心数量。
- 背包满、工具不足或抽到不可重复武器时安全停止，不吞掉剩余道具。

### 本地公会

- 没有公会的旧存档首次进入时可建立单人本地公会。
- 公会数据保存在主存档的 `offlineUnion` 字段。
- 公会任务不再依赖竞技场或其他玩家。
- 公会商店取消会员等级门槛。
- 材料类商品不受每日限购。
- 武器仍保持只能拥有一件。
- 50,000 G币可兑换一个公会奖章。

### 副本与 M币循环

- 精英副本可以无限重复挑战，不再收取重玩 M币。
- Boss/特殊副本可以无限挑战，不再消耗每日次数。
- 精英及 Boss/特殊副本通关后可翻牌。
- 对应翻牌池加入随敌人等级增长的 M币奖励。
- 普通剧情关卡不直接掉落 M币；结算翻牌抽到 25 M币时使用独立 M币标识并计入 M币，不再显示为 G币。

### 本地竞技场

- 主竞技场固定提供 15 个本地 AI 对手，不再请求在线排行榜或远程玩家数据。
- 每日保留 15 次挑战；进入战斗时立即消耗次数并保存。
- 每个对手被挑战后独立冷却 30 分钟，胜利、失败和中途退出均不能绕过。

### 活跃度

- 活跃度达到 100 后不再自动清零。
- 满 100 时显示“刷新活跃度”按钮，经二次确认后重置活跃值、礼包状态和任务进度。
- 刷新前明确提示未领取奖励会消失。

### 稳定性

- 修复高等级精英副本缺失音乐资源导致的加载错误。
- 对翻牌阶段的空奖励、重复武器、材料背包满等情况增加保护。
- Go 服务端限制 AMF 解析和历史数据规模，避免异常内存增长。
- 修改器“禁止自动捡取医疗箱”采用勾选即禁止的明确语义；新存档及缺少该字段的旧存档默认开启禁止。

### 开发工具

- 建立基于 FFDec CLI 的模块化开发工作台。
- 提供 AS3 源码编辑、旧版嵌入 XML 编辑、SymbolClass 检查和构建/导出面板。
- 支持导出脚本、图片/声音/文本/BinaryData、符号映射和 CS6 XFL。
- 主游戏构建会从只读基线导入 AS3，并回灌 21 份嵌入配置。
- 普通构建不覆盖运行版；多目标部署带构建锁、预写入和失败回滚。
- 正式 Go 服务端源码已从运行目录独立到 `server/`，`offline/` 只保留构建产物和兼容入口。

## 当前限制

- 在线排行榜、真实玩家竞技场、跨玩家公会等纯联机功能不可用；竞技场已由本地 AI 替代。
- 本地公会只有玩家本人，不模拟完整多人生态。
- Flash 的显示对象和时间轴界面限制了新增复杂 UI 的速度。
- 部分功能只有静态回归测试，仍需要进入游戏人工验证。
- 反重力地图、合金2关卡、皮肤系统和大型 Roguelike 模式尚未实现。
