# 项目现状

## 当前目标

把原本依赖 4399 页面、登录、支付和远程存档的游戏改造成可长期保存、可维护、可扩展的单机版本，同时尽量保留原游戏流程和资源。

## 已实现

### 离线运行

- 使用正式规则等级，不启用测试模式及测试水印。
- Go 后端提供静态资源、API 桩和权威存档服务。
- 游戏通过本地 HTTP 地址加载主体和分包资源。
- 启动器会检查后端状态，再启动独立 Flash Player。

### 存档

- `saves/game_save.bin` 是权威存档。
- 同步生成便于查看和修改的 JSON。
- SQLite 保存最近的历史版本。
- Flash SharedObject（SOL）不参与读取和回退。
- 提供便携版修改器和清除存档脚本。
- portable 游戏/修改器启动脚本与 1.2.3 对齐：根目录识别、API 预检、端口切换及退出清理均已启用；关闭可见窗口后会强制结束同目录后台进程，不再无限等待残留 Flash/浏览器 helper。
- 道具背包最低容量提升为 144 格；新角色直接生效，旧存档读档时自动扩容且不缩减更大容量。
- 材料背包在原始 36 格基础上增加三页（每页 30 格），最低容量为 126 格；新旧存档均生效且不缩减更大容量。
- 读档/存档会剥离虚空档：等级<=1 且无主武器/副武器/车辆的角色槽会被清空；服务端保存前也会剥离并写回清理后的数据，不再因默认名 4399小战士 漏网。
- M币出现 NaN 时自动归零。

### 商城与货币

- M币交易按照账户余额正常校验和扣款。
- 商城购买数量上限扩大到 9,999,999。
- 绿色芯片不直接出现在普通商店。
- 原材料和晶体类 M币商品合并为“自选强化礼包”。
- 定制装备、往期装备和现版本无法获取的精选装备加入商城，并按档位提高价格。
- 累计充值奖励改为读取账户当前持有的 M币。
- 成长礼包改为离线直接购买/激活。
- 等级和 G币的一步到位 M币入口被隐藏，M币主要用于材料、装备和可玩系统。

### 角色与成长

- 改名免费。
- 头像使用 G币永久解锁，并保存解锁列表。
- 全能训练支持输入提升级数。
- 战斗力、耐久和相关汇总使用大数值，避免 32 位整数溢出为负数。
- 主界面战斗力显示避免无意义的小数尾数。

### 战斗核心

- 普通、优质和稀有战斗核心均有批量开启入口。
- 玩家可以输入开启数量。
- 每次开启独立消耗一个核心和对应拆解器。
- 三档核心分别固定获得 5 万、10 万、20 万 G币及对应保底材料；稀有核心的三种高级合成材料为固定获得，不再按 10% 概率结算。
- 核心道具说明改为直接改写原始 ItemsDefine（不再改 getDefine 副本），并同步嵌入 XML，确保悬停介绍显示“固定获得”。
- 单次和批量拆解完成后显示实际奖励名称与合计数量，不再只显示拆解核心数量。
- 背包满、工具不足或抽到不可重复武器时安全停止，不吞掉剩余道具。

### 本地公会

- 没有公会的旧存档首次进入时可建立单人本地公会。
- 公会数据保存在主存档的 `offlineUnion` 字段。
- 公会任务不再依赖竞技场或其他玩家。
- 公会商店取消会员等级门槛。
- 材料类商品不受每日限购。
- 武器仍保持只能拥有一件。
- 50,000 G币可兑换一个公会奖章。

### 副本与 M币循环

- 精英副本可以无限重复挑战，不再收取重玩 M币。
- Boss/特殊副本可以无限挑战，不再消耗每日次数。
- 精英及 Boss/特殊副本通关后可翻牌。
- 对应翻牌池加入随敌人等级增长的 M币奖励。
- 普通剧情关卡不直接掉落 M币；结算翻牌抽到 25 M币时使用独立 M币标识并计入 M币，不再显示为 G币。

### 本地竞技场

- 主竞技场固定提供 15 个本地 AI 对手，不再请求在线排行榜或远程玩家数据。
- 每日保留 15 次挑战；进入战斗时立即消耗次数并保存。
- 每个对手被挑战后独立冷却 30 分钟，胜利、失败和中途退出均不能绕过。

### 活跃度

- 活跃度达到 100 后保持不变，允许玩家按任意顺序领取五档奖励。
- 五档奖励全部领取后，由活跃奖励自身立即把活跃值、礼包状态和整套活跃任务进度重置为新一轮；跨天不会重置活跃度或活跃任务。
- 自动刷新不会在同一会话重复计算登录任务，新一轮从 0 活跃度开始；每次领奖后立即保存领取与刷新状态。
- 修改器提供“生成100活跃度未领奖状态”：由服务端专用接口直接修改权威存档，将全部活跃任务标记完成、活跃值设为100、五档奖励保持未领取；写入前后均执行 AMF 往返验证并建立备份，避免浏览器整档编辑造成概率性读档失败。

### 任务刷新

- 普通任务五个槽位分别在领取后冷却 15 分钟；五个任务全部完成时立即生成下一轮。
- 挑战任务分别冷却 30 分钟，不因整轮完成或跨天而提前刷新。
- 收集任务三个槽位分别在领取后冷却 15 分钟；三个任务全部完成时立即刷新下一轮。
- 每周扫荡任务无冷却，领取奖励后可以立即再次接取。
- 上述任务均不参加每日重置；精英副本每日增加一次免费机会仍由独立的副本系统处理。

### 稳定性

- 玩家副本旧存档中 `winB=true` 且缺少 `readyAt` 的状态会自动迁移为可挑战，并恢复完整 Boss 血量，不再永久显示“冷却 0 秒”。
- 主存档写入保留 `game_save.last-good.bin`；替换中断时自动恢复上一份有效存档，且拒绝角色槽位数量异常减少的覆盖请求。
- 修改器启动器优先使用新版 `server.exe`，发行包中的 `modifier-engine.exe` 与其保持同一构建，避免旧引擎绕过槽位修复。
- 选服页隐藏覆盖游戏公告正文的旧“新”徽章；主界面累计礼包按钮改为“累计MB奖励”，并按真实时间轴层级替换独立文本。
- 精英/玩家/特殊副本页面只在首次打开或切换标签时播放入场动画；每秒冷却检查改为状态变化时静默刷新，避免页面持续闪烁。
- 修复高等级精英副本缺失音乐资源导致的加载错误。
- 对翻牌阶段的空奖励、重复武器、材料背包满等情况增加保护。
- Go 服务端限制 AMF 解析和历史数据规模，避免异常内存增长。
- 修改器“禁止自动捡取医疗箱”采用勾选即禁止的明确语义；新存档及缺少该字段的旧存档默认开启禁止。
- 选服页更新公告确认从根目录 `公告.txt` 加载；加载长文本后按实际 `textHeight` 扩展内容区并刷新、复位滚动条，避免固定 210 像素高度截断公告。`README.txt` 不参与该公告加载链路。
- 兑换商城移除仅允许 10ms 误差的双时钟“加速器”检测，避免不同电脑计时精度、校时或休眠恢复造成倒计时误停；到零时立即刷新。商品刷新改为最多两次遍历商品池并按 ID 去重，不再在主线程重复循环最多 2000 轮。计时器会在所有首批库存提前返回路径之前启动并立即更新一次显示。刷新时间改用绝对本地时间，并在单次会话中用 `getTimer()` 提供单调时钟兜底；旧版负数时间、空值、损坏值及异常未来时间会自动迁移，避免重启后长期卡在 5 分钟。
- 修复 Go AMF3 解码器对关联数组登记对象引用过晚的问题；修改器解析含关联槽位的 Flash 存档时不再把晶体 `addArr` 等引用错接到其他对象。修改器保存时以 `GCoin`/`MCoin` 为权威并自动同步 `GCoin2`/`MCoin2`，界面不再把备用货币字段作为独立输入项。
- 加强 1.1 老存档迁移：本地启动时初始化真实 `getSaveDate` 与 `severTime.nowTime`，零日期旧档首次进入会触发一次每日刷新并把最后登录日期更新为当天；活跃奖励补齐 5 档、活跃任务补齐 7 项，缺失日期对象安全初始化。修改器递归还原 AMF 稀疏数组，旧档的特殊副本冷却和任务索引在编辑往返后仍保持 Array 类型。

### 开发工具

- 建立基于 FFDec CLI 的模块化开发工作台。
- 提供 AS3 源码编辑、旧版嵌入 XML 编辑、SymbolClass 检查和构建/导出面板。
- 支持导出脚本、图片/声音/文本/BinaryData、符号映射和 CS6 XFL。
- 主游戏构建会从只读基线导入 AS3，并回灌 21 份嵌入配置。
- 普通构建不覆盖运行版；多目标部署带构建锁、预写入和失败回滚。
- 正式 Go 服务端源码已从运行目录独立到 `server/`，`offline/` 只保留构建产物和兼容入口。

## 当前限制

- 在线排行榜、真实玩家竞技场、跨玩家公会等纯联机功能不可用；竞技场已由本地 AI 替代。
- 本地公会只有玩家本人，不模拟完整多人生态。
- Flash 的显示对象和时间轴界面限制了新增复杂 UI 的速度。
- 部分功能只有静态回归测试，仍需要进入游戏人工验证。
- 反重力地图、合金2关卡、皮肤系统和大型 Roguelike 模式尚未实现。
